Quick Theory

Before using the tool, here is the core idea behind context-free grammars and tree construction.

What Is A CFG?

A context-free grammar (CFG) is a formal system with non-terminals, terminals, a start symbol, and production rules. Rules describe how a non-terminal can be replaced to generate valid strings.

What Is Derivation?

Derivation is the step-by-step process of applying grammar rules from the start symbol to reach the final input string. Leftmost and rightmost derivations differ by which non-terminal is expanded first.

What Is A Parse Tree?

A parse tree shows the same derivation structurally. Internal nodes are non-terminals, leaves are terminals, and each parent-to-children expansion corresponds to one grammar rule application.
